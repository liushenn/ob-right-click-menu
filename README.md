# Right-click Menu

Pick exactly which items show up in Obsidian's editor right-click menu — and pin any command to it.

## Features

- **Hide anything**: every item that shows up in the editor context menu (built-in ones like Cut/Copy/Paste, plugin items, submenus) is collected automatically. Uncheck an item and it disappears.
- **Pin commands**: search all Obsidian commands and put the ones you use on top of the context menu.
- **Separator toggle**: keep your pinned commands visually apart from the native items.
- **Bilingual UI**: 中文 / English.

## Usage

1. Enable the plugin in **Settings → Community plugins**.
2. Open **Settings → Right-click menu**.
3. Right-click a few times in a note so the menu items get collected.
4. Uncheck what you don't want, search for commands to pin at the top.

## Installation (manual)

Copy `main.js` and `manifest.json` into `<vault>/.obsidian/plugins/ob-right-click-context-menu/` and enable the plugin.
